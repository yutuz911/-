# GMP偏差调查知识库

本知识库用于增强 `gmp-deviation-capa-assistant` 的专业覆盖面。使用时应结合企业内部SOP、产品工艺特性、注册资料、质量标准和实际证据，不应把本知识库当作企业最终决策依据。

## 1. 偏差分类库

### 生产工艺偏差

常见场景：

- 温度、压力、时间、转速、速度、真空度、喷雾速率、干燥终点、混合时间、压片压力、包衣增重等工艺参数超限。
- 工序顺序错误、操作步骤遗漏、工艺等待时间超限。
- 中间体暂存时间或条件超限。
- 实际收率、物料平衡、片重、硬度、脆碎度等过程控制异常。

调查重点：

- 批记录、电子趋势、设备报警、操作调整记录。
- CPP与CQA关联关系。
- 超限幅度、持续时间、发生阶段、是否重复发生。
- 中间体/成品检测结果、稳定性历史、同类批次趋势。

### QC检验偏差、OOS与OOT

常见场景：

- 检验结果超出质量标准，或趋势明显偏离历史水平。
- 系统适用性失败、空白干扰、峰形异常、积分异常。
- 样品制备、标准品、试剂、仪器、方法、计算或审计追踪异常。

调查重点：

- 先开展实验室初步调查，不应简单通过复验消除异常。
- 核查样品、标准品、试剂、溶液、仪器状态、方法适用性、系统适用性、计算公式、原始图谱、审计追踪。
- 若实验室错误不能确认，应扩大至生产过程和批次质量调查。
- 批次放行应等待OOS/OOT调查结论和QA批准。

### 文件记录与数据完整性偏差

常见场景：

- 批记录漏填、补填、签名延迟、修改不规范。
- 电子数据缺失、审计追踪异常、时间戳异常。
- 原始记录与汇总记录不一致。

调查重点：

- 区分“实际操作是否完成”和“记录是否同步、真实、完整”。
- 核查原始记录、设备日志、电子记录、人员访谈、现场状态。
- 评估ALCOA+原则：可归属、清晰、同步、原始、准确、完整、一致、持久、可获得。
- 数据完整性事件通常不宜低估，应评估是否存在系统性问题或人为篡改风险。

### 设备设施偏差

常见场景：

- 设备报警、故障停机、校准超期、确认状态异常。
- 关键仪表偏差、传感器漂移、维护不到位。
- 公用系统异常，如压缩空气、纯化水、空调净化系统。

调查重点：

- 设备维护、校准、确认、点检、报警、维修记录。
- 异常发生时间与产品接触、关键工艺步骤的对应关系。
- 是否影响多个批次或多个产品。
- 是否需要重新确认、再验证或增加预防性维护。

### 环境监测与微生物偏差

常见场景：

- 洁净区悬浮粒子、沉降菌、浮游菌、表面微生物超警戒限或行动限。
- 压差、温湿度、换气、气流组织异常。
- 无菌灌装、关键洁净区人员行为异常。

调查重点：

- 区分警戒限与行动限，但重视趋势和复发。
- 核查人员行为、清洁消毒、气流、压差、培养基、取样操作、培养条件、历史趋势。
- 涉及无菌药品和关键区域时，应升级风险评估。
- 评估对当日生产批次、暴露产品、无菌保证水平的影响。

### 物料与供应商偏差

常见场景：

- 物料检验异常、包装破损、标签错误、储存条件超限。
- 供应商变更未充分评估，到货质量趋势下降。

调查重点：

- 物料批号、供应商、COA、到货验收、检验结果、储存运输条件。
- 是否已有同供应商同类问题。
- 是否影响已使用批次、在库物料和在制产品。
- 是否需要供应商调查、质量协议回顾或供应商CAPA。

### 包装标签偏差

常见场景：

- 标签、说明书、批号、有效期、装量、外箱信息错误。
- 混批、混料、包装材料领用或销毁记录异常。

调查重点：

- 标签版本、物料编码、批号有效期、线清场、物料平衡。
- 已包装数量、待包装数量、隔离状态和市场流向。
- 涉及错标、混批、已出厂时，应升级质量负责人和召回风险评估。

### 计算机化系统偏差

常见场景：

- 系统宕机、权限异常、数据同步失败、审计追踪关闭或缺失。
- 自动采集数据与人工记录不一致。

调查重点：

- 系统验证状态、权限管理、审计追踪、备份恢复、接口日志。
- 是否影响GxP关键数据完整性。
- 是否需要临时人工控制、数据恢复确认、变更控制或再验证。

## 2. 风险分级参考

低风险通常具备：

- 不直接影响产品质量、安全性、有效性。
- 偏差轻微、短时、可追溯，证据充分。
- 不涉及关键工艺参数、关键质量属性、无菌保证、数据完整性或已放行产品。

中风险通常具备：

- 可能影响过程控制或产品质量，但已有部分证据显示风险可控。
- 涉及CPP、重要工艺参数、记录完整性、设备状态或检验趋势。
- 需要补充调查后才能形成最终结论。

高风险通常具备：

- 可能影响患者安全、产品安全性/有效性/质量一致性。
- 涉及无菌保证、微生物污染、OOS无法排除、数据完整性重大缺陷、错标混批、已上市产品。
- 同类偏差反复发生，CAPA失效。

风险初判必须说明依据，并保留QA最终确认。

## 3. 调查证据矩阵

人：

- 培训记录、资质授权、访谈记录、班次交接、人员行为观察。
- 是否存在SOP理解偏差、疲劳、工作负荷、人员变更。

机：

- 设备状态、报警、维护、点检、校准、确认、维修、趋势曲线。
- 是否存在防错不足、报警限不合理、控制系统波动。

料：

- 物料批号、供应商、放行状态、储存条件、运输记录、前序检验结果。
- 是否存在批间差异、含水量异常、包装破损、标签错误。

法：

- SOP、工艺规程、检验方法、记录模板、异常处置流程。
- 是否明确标准、操作步骤、超限处置、上报路径和复核要求。

环：

- 温湿度、压差、洁净级别、清洁消毒、虫害、交叉污染风险。
- 无菌场景应额外关注气流、人员动线、暴露时间。

测：

- 仪器校准、方法适用性、样品制备、标准品试剂、计算公式、审计追踪。
- 是否存在测量误差或数据完整性问题。

管理：

- 偏差趋势、CAPA有效性、变更控制、供应商管理、质量文化。
- 是否存在反复发生但未升级的系统性问题。

## 4. 质量影响评估框架

评估时至少覆盖：

- 影响对象：本批、相邻批次、同设备批次、同物料批次、已放行产品、市场产品。
- 影响阶段：原辅料、生产中间体、半成品、成品、稳定性、留样、市场投诉。
- 质量属性：含量、有关物质、溶出、外观、水分、粒度、均匀度、装量、微生物限度、无菌、内毒素、包装完整性。
- 证据强度：原始记录、电子数据、检验报告、趋势图、访谈、现场观察。
- 当前结论：无直接证据、风险可控、需补充检测、需暂缓放行、需扩大调查。

推荐表达：

“基于目前资料，暂未发现直接证据表明该偏差已导致产品质量不合格；但由于……尚未确认，建议在……完成后由QA形成最终批次处置结论。”

## 5. CAPA库

纠正措施示例：

- 隔离受影响批次、物料或包装材料。
- 复核批记录、电子记录、趋势数据、设备报警和原始检验数据。
- 完成补充检测或复核检测。
- 完成设备检查、校准确认、故障排查或维修。
- 对已放行产品开展流向和召回风险评估。

预防措施示例：

- 修订SOP或记录模板，明确异常处置和上报路径。
- 优化报警限、预警限、工艺参数趋势监控。
- 增加设备预防性维护或关键仪表校准频次。
- 开展针对性培训和现场操作确认。
- 建立同类偏差月度/季度趋势回顾。
- 对供应商发起质量调查、质量协议修订或绩效再评估。
- 对计算机化系统权限、审计追踪、备份恢复机制进行加强。

有效性确认示例：

- 后续连续3批或3个月无同类偏差。
- 现场观察操作符合修订SOP要求。
- 培训后考核通过率达到企业要求。
- 趋势图显示关键参数波动降低。
- QA抽查记录完整率提升。

## 6. HTML报告内容组织

用于交互式页面时，将内容压缩成“先看结论，再看证据”的结构：

- 管理层摘要：100-180字，讲清发生了什么、初判风险、当前建议。
- 风险仪表盘：风险等级、偏差类型、证据充分度、批次状态。
- 关键时间线：发生、发现、临时措施、待完成节点。
- 调查证据：按人机料法环测分组。
- 根因分析：5Why + 矩阵。
- 质量影响：用“已支持/待确认/风险点”三类呈现。
- CAPA：可筛选纠正措施/预防措施。
- QA关注点：作为最终审核清单。

视觉原则：

- 使用克制的药企质量风格：深墨色、青绿色、蓝色、少量琥珀色提示风险。
- 不做营销式大标题，不用过度装饰。
- 长文字折叠，关键结论前置。
- 表格要能横向滚动，移动端不破版。
