# GMP偏差调查与CAPA助手：评委演示案例

以下案例均为脱敏虚构案例，可直接复制到 WorkBuddy 中测试本 Skill。

## 案例1：生产工艺参数短时超限

请使用“GMP偏差调查与CAPA助手”生成偏差调查报告草案。

偏差信息如下：

某口服固体制剂产品A，批号A202608001，在湿法制粒干燥过程中，工艺规程要求进风温度控制范围为55-65℃。批生产记录显示，2026年8月20日14:20-14:35期间，进风温度达到66℃，持续约15分钟。操作员巡检发现后立即调整设备参数，温度恢复至范围内。该批中间体水分检测结果为2.3%，符合内控标准2.0%-3.5%。目前成品检验尚未完成。请生成偏差调查报告，并给出根因分析、质量影响评估和CAPA建议。

## 企业资料投递与长期学习演示输入

请使用“GMP偏差调查与CAPA助手”进入企业资料投递与长期学习模式。以下为脱敏企业资料摘要：

1. 企业偏差分级规则：涉及关键工艺参数短时轻微超限且已有中间体合格证据的，一般初判为中风险；涉及无菌保证、数据完整性、已放行产品或OOS无法排除的，应初判为高风险并升级质量负责人。
2. CAPA程序：纠正措施建议10个工作日内完成，预防措施建议30个工作日内完成，CAPA完成后应在连续3批或3个月内做有效性确认。
3. 报告偏好：报告中必须包含“QA审核关注点”“需补充确认事项”“批次处置建议”；不得直接写“确认无影响”。
4. 历史偏差台账：近6个月湿法制粒干燥工序出现3次温度短时超限，其中2次涉及同一台干燥设备。

请生成企业知识包草案、学习台账更新、CAPA复查提醒和GMP趋势预测提醒。
