# 企业GMP长期学习台账

本台账是 `gmp-knowledge-governor` 的长期学习知识库，用于沉淀主技能 `gmp-deviation-capa-assistant` 每次使用后的可复用数据知识。

默认规则：

- 默认后台写入，不在普通偏差报告中展开。
- 只保存脱敏摘要、标签、规则候选、风险模式、CAPA模式、复查提醒和来源标识。
- 不保存企业文件原文、未脱敏个人信息、患者信息或商业秘密全文。
- AI推断只能标为候选知识，后续需由企业QA、质量体系或授权人员确认。


- 来源标识：用户偏差案例；报告示例 DEV-A202608001-20260820
- 数据类型：偏差
- 产品/剂型：口服固体制剂；产品名称已泛化为产品A
- 工序/系统/设备：湿法制粒干燥；进风温度控制
- 偏差或知识点：工艺规程要求进风温度55-65℃，实际66℃持续约15分钟；中间体水分2.5%，符合内控2.0%-3.5%；成品检验未完成。
- 风险等级建议：中风险候选；依据为CPP短时超限且成品检验未完成。
- 根因模式：设备温控波动、报警/预警设置、现场趋势监控或异常上报机制需核查；不得直接归因于人员操作失误。
- CAPA模式：复核设备温控曲线和报警记录；完成成品检验趋势评估；评估报警限和SOP短时超限处置要求；开展针对性培训与现场确认。
- 有效性确认/复查节点：后续连续3批或企业规定周期内无同类温度超限；CAPA完成后启动有效性确认。
- 可复用规则候选：短时轻微超限且中间体检测合格时，仍需等待成品检验、设备趋势和QA审核后再形成最终批次处置结论。
- 需人工确认：企业偏差分级程序、设备报警记录、成品检验结果、同设备/同工序历史趋势。
- 后续提醒：若同设备或同工序在3-6个月内再次出现温度超限，应提示重复偏差和CAPA有效性复盘。
- 记录状态：候选
