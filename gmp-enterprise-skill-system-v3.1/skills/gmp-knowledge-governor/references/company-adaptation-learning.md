# 企业资料适配与长期学习知识库

本文件用于支持企业合规资料投递、企业个性化知识包、长期学习台账、CAPA复查提醒和GMP趋势预测。它解决的不是单份偏差报告生成，而是让每家企业逐步形成自己的质量体系语境。

## 1. 企业资料投递入口

可接收的企业资料类型：

- 偏差管理程序、CAPA管理程序、OOS/OOT调查程序。
- 批生产记录模板、偏差报告模板、CAPA表单、质量风险评估模板。
- 工艺规程、清洁验证程序、设备确认程序、环境监测程序。
- 组织架构、质量职责、审批权限、质量负责人授权规则。
- 历史偏差台账、CAPA台账、审计缺陷、检查缺陷、投诉台账。
- 产品目录、剂型、关键工序、关键设备、关键物料、供应商清单。

资料投递后应先输出：

- 已识别资料清单。
- 可提取企业规则。
- 需人工确认的敏感或模糊条款。
- 资料缺口。
- 是否适合用于后续个性化报告。

## 3. 长期学习台账结构

每次用户提供新偏差、新报告或新数据后，应形成一段“学习台账更新”。当由主技能自动调用时，默认写入长期学习台账，不在报告正文中展开；当用户要求查看学习结果、预测提醒或复查提醒时，再输出给用户：

```markdown
## 学习台账更新
- 数据日期：
- 来源资料：
- 新增偏差类型：
- 关联产品/工序/设备：
- 初判风险等级：
- 根因模式：
- CAPA类型：
- 复查日期：
- 有效性确认日期：
- 是否与历史事件相似：
- 新增企业偏好：
- 后续提醒：
```

## 4. 复查提醒规则

应主动提示以下事项：

- CAPA完成期限临近或逾期。
- CAPA已完成但有效性确认未启动。
- 同类偏差在3个月、6个月或12个月内重复出现。
- 同设备、同工序、同物料或同供应商偏差频率升高。
- 审计缺陷对应的整改措施未闭环。
- 偏差报告缺少关键证据，如趋势记录、原始图谱、审计追踪、成品检验。
- 批次处置结论依赖的补充检测尚未完成。

提醒输出应包含：

- 需复查对象。
- 触发原因。
- 建议复查资料。
- 责任部门建议。
- 建议完成时限。
- 风险等级。

## 5. GMP趋势预测逻辑

预测提醒不应写成确定性判断，应使用“趋势提示”“潜在风险”“建议关注”。

常见预测信号：

- 同一设备连续出现参数波动、报警或维护异常。
- 同一工序多次出现时间、温度、压力、收率、物料平衡异常。
- 同一人员或班组多次出现记录缺陷、交接班遗漏。
- 同一供应商物料检验异常、包装破损或交付偏差增加。
- 同一洁净区环境监测接近警戒限或趋势上升。
- 同一CAPA措施反复出现但偏差仍复发。

预测输出格式：

```markdown
## GMP趋势预测提醒
| 预测对象 | 风险信号 | 可能影响 | 建议动作 | 优先级 |
|---|---|---|---|---|
```

## 6. 个性化报告适配规则

如果已有企业知识包，生成偏差报告时应优先套用企业口径：

- 使用企业自己的风险等级名称和定义。
- 使用企业偏差报告字段顺序。
- 使用企业CAPA完成时限和有效性确认周期。
- 使用企业部门名称和审批角色。
- 引用企业SOP条款时，必须注明来自用户提供资料。
- 若企业规则与通用GMP建议冲突，应提示“需QA确认”，不得自行覆盖企业程序。

## 7. 隐私与边界

- 不应要求用户提供未脱敏的患者信息、个人敏感信息或商业秘密，除非企业内部环境明确允许。
- 对企业资料的引用应尽量使用“企业偏差管理程序要求……”而不是泄露完整原文。
- 当前没有持久化数据库或无法写入长期学习台账时，应生成可保存的企业知识包/学习台账片段；普通报告中不必长篇说明，仅在用户需要持续学习或复查提醒时提示保存。
