# 使用说明

## 安装方式

把 `skills` 文件夹下的三个目录放入 Codex/WorkBuddy 的 skills 目录：

- `gmp-deviation-capa-assistant`
- `gmp-knowledge-governor`
- `gmp-output-contract-renderer`

使用时优先调用主Skill：

```text
$gmp-deviation-capa-assistant
请根据以下偏差描述生成偏差调查报告，并输出HTML版本……
```

当任务涉及知识库、训练材料或企业长期学习时，系统会组合 `gmp-knowledge-governor`。

当任务涉及JSON约束、固定字段或HTML UI时，系统会组合 `gmp-output-contract-renderer`。

## 推荐演示路径

1. 打开 `deliverables/企业GMP资料投递与长期学习入口_新版.html`，展示企业资料投喂和长期学习能力。
2. 打开 `deliverables/交互式偏差调查报告示例_企业级新版.html`，展示偏差报告从长文变成可交互页面。
3. 打开 `deliverables/GMP智能体训练材料清单_企业级完善版.xlsx`，展示知识库来源、训练材料、能力边界、评估指标和JSON输出契约。
4. 讲解“一个主Skill + 两个辅助Skill”的职责边界。

## 输出边界

本系统可以真实指导偏差调查准备、证据收集、CAPA设计和QA复核，但不能替代企业正式质量决策。报告中的风险等级、质量影响、CAPA和批次处置均需企业QA最终确认。
