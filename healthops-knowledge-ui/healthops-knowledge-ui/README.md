# HealthOps 医学知识库 UI 原型

这是一个面向健康运营岗位作品集的本地 Web 原型。它用于展示如何把客户提供的医学/健康资料沉淀为可检索、可审核、可测试的专属知识库。

## 核心能力

- 星体流星式知识图谱：每个症状、疾病或知识对象是一颗围绕知识星体运行的流星。
- 搜索聚焦：搜索病症、症状或关键词后，命中的流星会放大并呈现结构化知识。
- 客户资料喂入：支持表单录入标题、类型、摘要、关键提示、证据等级、风险等级、来源和输出边界。
- JSON 导入导出：支持客户批量导入资料，也可以导出当前知识库。
- 本地保存：数据保存在浏览器 localStorage 中，刷新后仍保留。
- 输出标准：内置健康内容回答结构、拒答边界、合规替代表达和特殊人群提醒。
- 幻觉测试：内置事实一致性、来源幻觉、急症识别、特殊人群、功效夸大、对抗诱导测试。

## 官方示例来源

原型内置示例只使用官方或权威来源入口：

- WHO Hypertension Fact Sheet
- WHO Diabetes Fact Sheet
- WHO SMART Guidelines
- CDC Diabetes Symptoms
- CDC Heart Attack Symptoms
- 国家药监局数据查询
- 国家卫健委成人高血压食养指南
- HL7 FHIR Clinical Reasoning

## 如何使用

直接打开 `index.html` 即可运行。无需后端服务。

推荐演示顺序：

1. 在搜索框输入“胸痛”，观察对应流星放大，并展示急症风险分流。
2. 搜索“高血压”，查看证据等级、来源和输出边界。
3. 在“客户资料喂入”表单新增一条客户资料。
4. 点击“导出 JSON”，展示知识库可迁移。
5. 点击“运行测试”，展示幻觉测试评分。

## 客户资料进入正式知识库的要求

正式运营时，客户资料必须补齐：

- 来源链接或文件出处
- 来源类型：指南、药品说明书、监管文件、论文、客户内部资料等
- 证据等级：A-E
- 风险等级：低/中/高
- 适用场景：科普、客服、社群、内容审核、AI 问答
- 禁用场景：诊断、处方、疗效承诺、停药换药建议
- 最近审核日期和复核人角色

## 医学边界

该原型用于健康运营、医学内容治理和 AI 问答安全展示，不提供诊断、处方或个体化治疗建议。涉及急症、孕期、儿童、老人、慢病、长期用药、肝肾功能异常等情况，应提示咨询医生、药师或急诊评估。
