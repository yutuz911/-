    Knowledge Pipeline

    运行方案架构

    1. 01客户上传资料、指南、说明书、FAQ 或运营内容
    2. 02识别来源类型，打上权威性、时效性、适用场景标签
    3. 03抽取疾病、症状、药品、检查、人群、禁用表达
    4. 04按证据等级与风险等级进入复核队列
    5. 05通过检索增强问答、内容审核、社群 SOP 输出
    6. 06用幻觉测试集持续评估输出是否安全可靠

    Output Standard

    健康内容输出标准

    标准回答结构

    结论先行 → 原因解释 → 行动建议 → 风险提醒 → 来源依据 → 边界声明。

    拒答边界

    不做诊断、不处方、不建议停药换药、不承诺疾病治疗效果，不编造指南或专家。

    合规替代表达

    用“健康科普、生活方式管理、营养支持场景、建议咨询专业人士”替代“根治、无副作用、人人适用”。

    特殊人群优先

    孕期、哺乳期、儿童、老人、慢病、肝肾功能异常、长期用药人群自动升级风险提示。
